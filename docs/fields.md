
# Словник полів моделі туристичного напрямку

Назви в колонці `name` стабільні. Їх без змін використовують розмітка форм, валідація JavaScript, типи TypeScript і ключі JSON під час обміну з API.

| Поле | name | Тип даних | Елемент | Обмеження |
|---|---|---|---|---|
| Назва напрямку | `title` | рядок | text | required, minlength 3, maxlength 100 |
| Зображення | `image` | URL | url | Необов'язкове, коректна URL-адреса |
| Категорія (регіон) | `category` | рядок | select | required, перший пункт порожній |
| Денний бюджет, $ | `price` | число | number | required, min 1, max 10000, step 1 |
| Дата додавання | `addedAt` | дата | date | required, min 2024-01-01, max 2027-12-31 |
| Опис | `description` | рядок | textarea | required, minlength 10, maxlength 500 |
| Доступність для туристів | `inStock` | логічне | checkbox | value="true"; знятий прапорець не надсилається |
| Код напрямку | `itemCode` | рядок | text | Необов'язкове, pattern `[A-Z]{2}-[0-9]{3}`, maxlength 6 |
| Ідентифікатор | `id` | рядок | hidden | Лише форма редагування |

## Призначення полів

- `title` — назва міста та країни.
- `image` — посилання на фотографію туристичного напрямку.
- `category` — географічний регіон розташування.
- `price` — орієнтовний денний бюджет туриста в доларах.
- `addedAt` — дата додавання напрямку до каталогу.
- `description` — короткий опис туристичного напрямку.
- `inStock` — доступність напрямку для туристів.
- `itemCode` — додатковий код туристичного напрямку у форматі UA-001.
- `id` — ідентифікатор напрямку, який передається під час редагування.

## Використання полів

Форма додавання розміщується на сторінці `admin.html`.

Форма редагування розміщується на сторінці `admin-edit.html` і використовує ті самі назви полів, але із заповненими початковими значеннями.

Ідентифікатор `id` передається прихованим полем лише під час редагування.

Форми використовують метод GET для демонстрації передавання даних через адресний рядок браузера.

У наступних лабораторних роботах ці назви полів використовуватимуться під час реалізації JavaScript, TypeScript та обміну даними з API.
