# Словник полів моделі туристичного напрямку
 
Назви в колонці `name` стабільні. Їх без змін використовують розмітка форм, модуль даних `js/data.js`, валідація JavaScript, типи TypeScript і ключі JSON під час обміну з API.
 
| Поле | name | Тип даних | Елемент форми | Обмеження |
|---|---|---|---|---|
| Ідентифікатор | `id` | рядок | hidden | Унікальний, латиниця й дефіс; параметр `id` у `details.html?id=…` |
| Назва напрямку | `title` | рядок | text | required, minlength 3, maxlength 100 |
| Категорія (регіон) | `category` | рядок | select | required: `europe`, `asia`, `north-america`, `africa` |
| Денний бюджет, $ | `price` | число | number | required, min 1, max 10000, step 1 |
| Дата додавання | `addedAt` | дата РРРР-ММ-ДД | date | required, min 2024-01-01, max 2027-12-31 |
| Найкращий місяць | `bestMonth` | ціле число | select | 1–12 **(нове в ЛР8)** |
| Доступність для туристів | `inStock` | логічне | checkbox | value="true"; знятий прапорець не надсилається |
| Код напрямку | `itemCode` | рядок | text | Необов'язкове, pattern `[A-Z]{2}-[0-9]{3}`, maxlength 6 |
| Зображення | `image` | URL | url | Фото шириною 800 px |
| Зменшене зображення | `imageSmall` | URL | url | Фото шириною 320 px для `srcset` **(нове в ЛР8)** |
| Альтернативний текст | `imageAlt` | рядок | text | required, описує вміст фото, а не назву **(нове в ЛР8)** |
| Опис | `description` | рядок | textarea | required, minlength 10, maxlength 500 |
| Клімат за сезонами | `climate` | масив об'єктів | – | Рядки таблиці на сторінці деталей **(нове в ЛР8)** |
 
## Вкладений масив `climate`
 
| Поле | name | Тип даних | Обмеження |
|---|---|---|---|
| Місяць | `month` | рядок | Назва місяця, заголовок рядка таблиці |
| Середня температура, °C | `temperature` | число | Може бути від'ємним |
| Опади, мм | `precipitation` | число | min 0 |
 
## Призначення полів
 
- `id` — ідентифікатор напрямку; за ним сторінка деталей знаходить позицію.
- `title` — назва міста та країни.
- `category` — географічний регіон; на картці виводиться назвою «Європа», «Азія», «Північна Америка», «Африка»; регіон «Африка» поки не має напрямків.
- `price` — орієнтовний денний бюджет туриста в доларах; форматується через `Intl.NumberFormat`.
- `addedAt` — дата додавання напрямку до каталогу; форматується через `Intl.DateTimeFormat`.
- `bestMonth` — номер найкращого місяця для подорожі; назва місяця береться з `Intl.DateTimeFormat`.
- `inStock` — доступність напрямку для туристів; на картці стає атрибутом `data-in-stock`.
- `itemCode` — додатковий код туристичного напрямку у форматі JP-001.
- `image`, `imageSmall` — велике та зменшене фото напрямку.
- `imageAlt` — альтернативний текст фото.
- `description` — опис напрямку; на картці схований до натискання «Показати опис».
- `climate` — кліматичні показники за сезонами для таблиці на сторінці деталей.
 
## Використання полів
 
Форма додавання розміщується на сторінці `admin.html`, форма редагування — на `admin-edit.html` з тими самими назвами полів.
 
З ЛР8 картки каталогу й сторінка деталей будуються з масиву `destinations` у модулі `js/data.js`.
 
З ЛР9 назви полів форми фільтрів (`query`, `category`, `sort`) є ключами об'єкта стану каталогу.
